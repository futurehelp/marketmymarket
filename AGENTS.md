# Market My Market

## Commands

- `npm run dev`: start the local Next.js dev server
- `npm run build`: create a production build
- `npm run start`: serve the production build
- `npm run lint`: run ESLint checks
- `npm run typecheck`: run strict TypeScript checks

## Structure

- `src/app/`: App Router pages, metadata, styles, and route entry point
- `src/components/`: organized layout, section, UI, and motion components
- `src/lib/`: typed content models
- `public/images/`: downloaded Market My Market assets
- `next.config.ts`: typed Next.js configuration

Keep the homepage native to Next.js. Do not add embedded source pages or remote page proxies.
